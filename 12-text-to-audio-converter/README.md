# 🗣️ Text to Speech Converter

A clean and responsive **Text-to-Speech web app** built using **React** that converts written text into spoken words using the **Web Speech API**.

## 🔗 Live Demo
https://sudhanshuverse.github.io/react-practice-projects/12-text-to-audio-converter/

## 🚀 Features
- Convert text into speech instantly
- Choose from available system voices
- Responsive design for all devices
- Simple and modern UI
